## 새로 드러난 분기 (현재 세션 편입 금지 — 메모만)

- **법인화 필요 시점**: 오픈뱅킹 이용기관(핀테크 서비스) 정식 등록 시 법인 권장. MVP 베타 종료 후 판단 분기. phase4 시드에 "v1.1 진입 전 법인화 결정"으로 기록 고려.
- **기부처 파트너 후보**: 페널티 이체 수취 기관 선정 — 공익법인(굿네이버스·유니세프·월드비전 등) 중 API 또는 정기후원 등록 경로 확인 필요. v1.1 준비 단계에서 리서치 과제.
- **OCR 영수증 인식 (v1.1~v2)**: 현재 파킹. 수동 입력 피로가 실사용 데이터에서 문제로 드러나면 우선순위 상향 재검토.
- **가족·커플 예산 공유**: v2+ 기능 후보. 강제성을 사회적 감시와 결합하면 리텐션 상승 가능. 현재 MVP 범위 외.
